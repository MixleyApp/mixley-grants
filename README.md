# Mixley Grants

A grants program for developers building on Mixley.

## Status

**Draft - applications opening soon.** Post & Earn is live today, but Grants is a separate program not yet active. This repository publishes the program structure so contributors can see what is coming and prepare applications ahead of the opening.

## Program overview

Mixley Grants funds developers who build on or contribute to the Mixley stack: the SDK, the Synthesis Data network, integrations, tooling and reference implementations. Grants are paid in MIX tokens once the token is deployed and in credits before that.

## Eligibility

An applicant must:

- Have a public body of work (a repository, a published integration, a written brief)
- Propose a concrete contribution to Mixley, not a vague idea
- Accept that payment is in MIX once the token is live and in credits before that
- Agree to the published review rubric and the decision of the reviewers

## Award tiers

| Tier | Award | Typical scope |
| --- | --- | --- |
| Micro | up to 50,000 credits | A bug fix, a small integration, a single example |
| Standard | up to 250,000 credits | A new integration, a reference implementation |
| Major | MIX grant, paid at token launch | A protocol-level contribution, a new tool |

The Major tier is settled in MIX once the token is deployed; until then it is recorded as a credit-equivalent commitment.

## Application process

1. Open an issue in this repository using the application template
2. Fill in the sections of the template
3. Reviewers score the application against the rubric and respond in the issue
4. Awards are recorded in the issue and settled through the credits ledger or, at token launch, in MIX

## Timeline

Applications are not yet open. The program will start after the first Synthesis Data network cycle is live and the credit ledger can settle grants. Watch this repository and the [Mixley X account](https://x.com/MixleyApp) for the opening announcement.

## Review

Applications are scored against the published [review rubric](./review/rubric.md). The rubric is public so applicants know what is evaluated.
